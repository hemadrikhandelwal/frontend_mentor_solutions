### What I learned

- While building this project, I strengthened my understanding of:

- Mobile-first responsive design using Tailwind breakpoints (md:)

- Proper use of Flexbox to split a card into image and content sections

- Handling layout issues caused by overflow-hidden and fixed heights

- Creating hover effects while using custom CSS variables

- Structuring clean and readable HTML for UI components



### Continued development

In future projects, I want to:

- Use Tailwind with a proper build setup (tailwind.config.js)

- Improve accessibility (focus states, ARIA roles)

- Practice more component-based UI layouts
